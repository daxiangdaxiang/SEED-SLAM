# Data

Most external SEED-SLAM datasets placed in this directory are ignored by Git
to avoid committing large or restricted files.

`Indoor_10_robots/` is the tracked ten-robot indoor benchmark. It contains
ground-truth trajectories and the corresponding robot-local object pose graphs.

The compact SemanticKITTI 05/07 inputs required by the published DBA snapshot
are already stored under `submodules/DBA-DRANPP/experiments/dba/`.
