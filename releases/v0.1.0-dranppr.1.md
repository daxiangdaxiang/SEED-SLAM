# DRANPPR Research Snapshot 1

**Experimental prerelease. Not a stable-default replacement for DBA/DRAN++.**

## Included

- Separate `submodules/DRANPPR` source snapshot; the existing DBA-DRANPP package
  and `data/Indoor_10_robots` remain unchanged.
- Optional native persistent local-factor and incremental Schur-model code,
  physical-objective replay, and sparse noise-calibration research tools.
- Fixed-quadratic asynchronous interface simulator, causal horizon-matched
  error budgets, adaptive update strength, and received-history predictors.
- New packet-corrected finite local-model response and frozen-forcing ablation.
- Nine compact model fixtures, original experiment summaries/audits, tests,
  and commands to reproduce the latest 140-run study without private paths.
- Snapshot provenance records content hashes including uncommitted research;
  the inherited source HEAD is not misrepresented as the complete snapshot.

## Results And Limits

Continuous model correction improves all 24 nonideal frozen-model ablations.
The three previously divergent long-delay cases do not diverge in the tested
2000-tick runs. Neither observation is a general convergence guarantee.

At equal application bytes, the new model-response candidate records **0 wins,
2 ties, and 26 losses against adaptive hold**, with 1.50--1.84x payload at equal
opportunities. It remains opt-in. No claim of superiority over adaptive hold,
new riMESA superiority, native nonlinear asynchronous SE3, or ATE improvement
is made by the fixed-quadratic study.

The original study passed 119 focused tests, including native checks in its
pinned local environment. Release automation runs the self-contained Python
subset and independently regenerates/audits the 140 experiments. Native build
instructions and the exact supported scope are in `submodules/DRANPPR/RELEASE.md`.

Fresh local package validation: 91 Python tests passed, two raw-Jacobian archive
checks skipped because the release ships reduced fixtures; 67 native C++ tests
and seven native integration tests passed using a new build of the packaged
source. Two packaging tests passed. No existing DBA or CCI algorithm was changed.

The evidence asset contains fresh release-workflow runs, not an unverified copy
of machine-local binaries. Original summary evidence is included in the source.
Common row/chart setup is pre-distributed; only incremental model setup bytes
are charged. Network time is simulated and excludes congestion.

## Reproduce

Use Python 3.9 for the pinned research environment:

```sh
python3 -m pip install -r releases/dranppr-requirements.txt
bash scripts/test_dranppr_python.sh
bash scripts/reproduce_dranppr.sh
```

This snapshot is published at the user's explicit request before the
communication-efficiency research acceptance gate passes. Further research
continues separately; this version is an immutable experimental checkpoint.
