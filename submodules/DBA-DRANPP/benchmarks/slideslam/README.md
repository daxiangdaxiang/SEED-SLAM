# SlideSLAM Processed-Bag Adapter Track (Not Native-Team Benchmark Eligible)

> **Eligibility status:** the three local parking-lot bags have disjoint
> original acquisition intervals. Concurrent replay with the official
> 60/60/0-second skips does not turn them into a native simultaneous team.
> They are retained only for adapter and solver smoke tests and must not be
> used for the strict native multi-robot benchmark. The qualifying benchmark
> source is MR.CLAM Dataset 1 under `benchmarks/mrclam`.

This track consumes three independently recorded SlideSLAM parking-lot runs.
It never partitions one trajectory, but the runs are not time-overlapping and
therefore do not satisfy the repository's native-team admission rule. The
frozen backend graph contains processed odometry and object observations only
when a compatible bag set is supplied.

The official SlideSLAM semantic-CLIPPER adapter estimates each pair transform.
A deterministic one-to-one projection then creates persistent cross-robot
object IDs. This projection is benchmark preprocessing, not an output claimed
by SlideSLAM. Associations, measurements, weights, and common initial states
are frozen before any optimizer runs.

## Build

Build the four required binaries from the repository root:

```sh
cmake -S . -B build -DBUILD_DPGO_TESTS=ON
cmake --build build --target object-based-multi-robot-example -j2

cmake -S baselines/LARPG -B baselines/LARPG/build-local
cmake --build baselines/LARPG/build-local --target larpg_object_graph -j2

cmake -S baselines/SESync/C++ -B baselines/SESync/C++/build-local
cmake --build baselines/SESync/C++/build-local --target SE-Sync -j2

cmake -S baselines/distributed-mapper/distributed_mapper_core/cpp \
  -B baselines/distributed-mapper/distributed_mapper_core/cpp/build
cmake --build \
  baselines/distributed-mapper/distributed_mapper_core/cpp/build \
  --target runDistributedMapper -j2
```

The official adapter is expected at:

```text
baselines/object_association/adapters/slideslam_official/build-local/slideslam_semantic_clipper
```

Its linked source is pinned to SlideSLAM commit
`63c78b9995b1e068dc0f185b3550e837b524833c`.

## Acquire And Audit

Install Python dependencies `rosbags`, `numpy`, and `scipy`. `gdown` is needed
only when the official Google Drive folder must be downloaded.

```sh
python -m benchmarks.slideslam.cli audit \
  --manifest benchmarks/slideslam/manifests/parking_lot_v1.json \
  --data-root datasets/SlideSLAM \
  --download
```

The audit requires three distinct bag paths and SHA-256 hashes, the required
odometry and semantic messages in every bag, and a non-empty effective replay
overlap after the official 60/60/0 second offsets. It rejects provenance marked
as generated by trajectory partitioning.

## Materialize

```sh
python -m benchmarks.slideslam.cli materialize \
  --manifest benchmarks/slideslam/manifests/parking_lot_v1.json \
  --data-root datasets/SlideSLAM
```

The canonical package is written to
`datasets/SlideSLAM/canonical/slideslam_parking_lot_v1/`. It includes canonical
JSONL, a global g2o graph, three common initialization seeds, and lossless
adapters for LARPG, DRAN, and Distributed Mapper. Existing canonical output is
never silently replaced.

## Dry Run

Dry-run validates all binaries, source pins, canonical hashes, nested checkout
revisions, and dirty-state fingerprints. It writes only `run_manifest.json` and
does not launch a solver.

```sh
DRY_RUN=true SEEDS='0 1 2' MAX_ITERS=50 \
  scripts/run_slideslam_object_benchmark.sh
```

## Run

```sh
SEEDS='0 1 2' MAX_ITERS=50 \
  scripts/run_slideslam_object_benchmark.sh
```

LARPG uses strict full shared-object uploads and broadcasts. DRAN uses complete
topology with `OBJECT_COMMUNICATION_POLICY=full`; trigger, innovation, age, and
budget suppression are disabled. Distributed Mapper uses zero rotation and pose
stopping thresholds for fixed-round runs. Because its existing executable emits
only a final state, the harness runs deterministic prefixes from the identical
initial graph to recover every externally evaluated round without modifying the
nested optimizer checkout.

Every state is ranked with the same external scalar chordal objective. Native
solver objectives remain diagnostics. Communication retains each method's real
logical payload definition rather than being rescaled into a common pose count.
Preparation time and solver process time are reported separately.

Outputs include:

```text
run_manifest.json
commands/
logs/
iterations/<method>_<seed>.csv
states/<method>_<seed>.jsonl
evaluations/<method>_<seed>.json
summary.csv
summary.md
```

SE-Sync supplies the centralized reference. Certification and status are kept
as reported by SE-Sync; an uncertified result is labelled only as a centralized
reference. The processed bags are not assumed to contain physical ground truth,
so trajectory and object errors are explicitly RMSE to that centralized
reference, not ATE, RPE, or object ground-truth error.

## Official Processed-Data Replay

The raw KITTI bag supplied with the download is a single-robot bag. The
official multi-robot demo is therefore replayed from the three processed-bag
scenes under `processed_data/{parking-lot,forests,scarabs}`. The canonical
headless runner is:

```sh
SCENE=parking-lot scripts/replay_official_slideslam_processed.sh
SCENE=forests scripts/replay_official_slideslam_processed.sh
SCENE=scarabs scripts/replay_official_slideslam_processed.sh
```

The runner preserves the upstream bag topics, replay offsets, rates, and
three-robot launch. It uses the official default `sloam.yaml`, namely
SlideGraph with CLIPPER (`use_slidematch: false`), and writes trajectories,
inter-robot transforms, runtime analysis, and communication statistics under
`association_result/`. The processed bags are replay artifacts rather than
the paper's surveyed ground-truth package, so the official replay can be
compared to Table VII runtime/communication values but cannot by itself
reproduce Table V inter-robot pose error or Table VI object precision/recall.

Generate the directly comparable Table VII report with:

```sh
python3 scripts/compare_official_slideslam_paper.py \
  --run urban=association_result/slideslam_official_processed_parking_lot_v1/<run> \
  --run forest=association_result/slideslam_official_processed_forests_v1/<run> \
  --run indoor=association_result/slideslam_official_processed_scarabs_v1/<run> \
  --output association_result/slideslam_official_paper_comparison.md
```
